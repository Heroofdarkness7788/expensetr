# Expense Tracker

An expense tracking platform designed to make it easier for engineers and employees to record, manage, and track work-related expenses.

## About the Project

I originally started working on this project before discovering this website. I found the platform later and decided to use it to showcase and continue developing the project.

The goal of the Expense Tracker is to simplify the process of recording work expenses and managing reimbursements. Instead of relying on spreadsheets, paper receipts, or scattered records, users can keep their expenses organized in one place.

## Features

* Record and submit work-related expenses
* Track submitted expenses and reimbursement status
* Organize expenses in one place
* Keep spending records easy to review
* Designed with engineers and employees in mind
* Simple and user-friendly interface

## Current Development

The project is still under development. I’m currently improving the user interface and working on additional features to make submitting expenses and processing reimbursements faster and easier.

## Future Plans
